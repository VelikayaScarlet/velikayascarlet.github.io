这套陆军编制以步兵为主。班、排、连按三个下级单位编成，营辖三个步兵连，团辖四营，师辖四团。从军开始，辖属数量不再固定。下表的符号是军用地图上标在单位框上方的**编制级别标记**，不是军衔标志。

## 从班到战区

| 单位 | 级别符号 | 编制 | 满编人数 |
|---|:---:|---|---:|
| 小组 | Ø | 含组长 | 4 |
| 步兵班 | ● | 班长一人，另辖三个四人小组 | 13 |
| 步兵排 | ●● | 三个步兵班、四人排部、八人直属武器班 | 51 |
| 步兵连 | ●●● | 三个步兵排、七人连部 | 160 |
| 步兵营 | &#124; | 三个步兵连、十二人营部、三十人直属火力排 | 522 |
| 步兵团 | &#124;&#124;&#124; | 四个步兵营、二十四人团部及二百一十人直属单位 | 2,322 |
| 旅 | × | 和团同级，编制比团大；规模随任务和单位类型而定 | 不定 |
| 步兵师 | ×× | 四个步兵团，另设师部和师直属单位 | 约 11,000 |
| 军 | ××× | 辖三个至六个师，也可另辖直属旅或团 | 仅各师合计约 33,000–66,000 |
| 集团军 | ×××× | 辖若干军，另设司令部和直属单位 | 不定 |
| 集团军群 | ××××× | 统一指挥若干集团军 | 不定 |
| 战区 | ×××××× | 按地理方向设立，辖集团军群，也可直接辖集团军 | 不定 |

这里借用北约式地图符号区分单位名称。旅记作「×」，团记作三条竖线；**两种符号不表示旅是团的上级**。师平时直接辖团，军也可以直接辖旅或团。旅既可以长期保留，也可以临时编成，正旅长和正团长都配上校，不另设准将。

## 各级直属编制

步兵班由一名中士班长统领，其余十二人分为三个小组。下士副班长兼任第一组组长；另两组通常由有经验的上等兵或下士带领，不固定配衔。排部由中尉排长、少尉副排长、上士排务长和通信员组成。连部则设上尉连长、中尉副连长、上士连务长，以及文书、通信员、补给员和卫生员各一名。

营部十二人包含正副营长以及参谋文书、通信、补给和卫生人员，直属火力排另计。团部二十四人与直属单位分开计算：炮兵连九十人、通信排十八人、运输补给连六十六人、维修队十六人、医疗队二十人。坦克不计入普通步兵团的员额，由装甲部队另行编列。

四个步兵团共 9,288 人，师部和师直属单位约 1,700 人，全师满编约 11,000 人。军部及军直属单位不计入表中的各师合计；集团军以上也按实际辖属统计，不定统一员额。

## 军衔与标准配职

军衔和职务分开。相邻层级常以「上一级副职、下一级正职」配同一军衔；少校和上尉例外，分别只对应副营长和正连长。集团军以上的多个职务可以同衔，指挥关系由职务决定。

| 类别 | 军衔 | 标准配职 |
|---|---|---|
| 将官 | 上将 | 战区司令、副战区司令、集团军群司令 |
| 将官 | 中将 | 副集团军群司令、集团军司令、副集团军司令、正军长 |
| 将官 | 少将 | 副军长、正师长 |
| 校官 | 上校 | 副师长、正旅长、正团长 |
| 校官 | 中校 | 副旅长、副团长、正营长 |
| 校官 | 少校 | 副营长 |
| 尉官 | 上尉 | 正连长 |
| 尉官 | 中尉 | 副连长、正排长 |
| 尉官 | 少尉 | 副排长 |
| 尉官 | 准尉 | 见习排级军官 |
| 军士 | 上士 | 排务长、连务长 |
| 军士 | 中士 | 正班长 |
| 军士 | 下士 | 副班长；也可任小组长 |
| 士兵 | 上等兵 | 已完成新兵阶段的士兵；有经验者可任小组长 |
| 士兵 | 列兵 | 初入伍的士兵 |
