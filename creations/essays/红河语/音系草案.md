### 1.1. E 与附标形式 é

单写 e 在整个词的词尾读 [ə]，在其他位置读 [e ~ ɛ]。词干加后缀后按整个词的位置确定读音，例如 me [mə]、met [metʰ ~ mɛtʰ]。词尾需要读 [e ~ ɛ] 时写作 é。é 是 E 的附标形式，不独立列入字母表，也不标记重音。

[e ~ ɛ]、[i ~ ɪ]、[h ~ x] 各组内部的读音差别不区别词义。

常规例词、例句的 IPA 采用代表音值简记：[e ~ ɛ] 写为 [e]，[i ~ ɪ] 写为 [i]，[h ~ x] 写为 [h]；动词词尾的 [je ~ jɛ] 写为 [je]。各组允许的读音范围在本音系说明中列出，其他文档不逐次重复。简记不改变原有读音范围。

### 1.2. Y 与 W 的元音、辅音用法

在词首后接元音时，y、w 分别读辅音 [j]、[w]，不采用元音读法。在其他位置，y、w 分别保留 [y]、[ɯ] 的音质；在同一语素内后接另一元音时作非音节成分 [y̯]、[ɯ̯]。

| 拼写 | 读音 |
|---|---|
| ya | [ja] |
| wa | [wa] |
| ye | [jə] |
| we | [wə] |
| yé | [je ~ jɛ] |
| wé | [we ~ wɛ] |
| yw | [jɯ] |
| yt | [ytʰ] |
| wt | [ɯtʰ] |
| tia | [tʰi̯a] |
| tya | [tʰy̯a] |
| tua | [tʰu̯a] |
| twa | [tʰɯ̯a] |

i、u 在同一语素内后接另一元音时，可分别作非音节成分 [i̯]、[u̯]；固定组合与双写长元音优先按各自规则读取。[i̯] 接近 [j]，[u̯] 接近 [w]。下加符号 [ ̯ ] 表示不独立构成音节。i、u、y、w 在这些位置仍保留各自音质，不合并为同一种滑音。

### 1.3. 动词原形词尾的固定读音

动词原形使用 -ie、-ye 两种后缀，分别接在辅音结尾与元音结尾的词干后：

| 动词后缀 | 固定发音 | 示例 |
|---|---|---|
| -ie | [iː] | baitie [baɪtʰiː]；falie [faliː] |
| -ye | [je ~ jɛ] | malaye [malaje ~ malajɛ] |

动词后缀 -ie 整体表示长元音，不按一般的 i、e 组合拆读。动词后缀 -ye 中的 y 固定为 [j]，词尾 e 保持 [e ~ ɛ]，不弱化为 [ə]，拼写不加附标。

上述读法按动词后缀识别，不将其他词尾相同的 ie、ye 一律视为动词后缀。一般的词尾 e、y 及元音组合仍按各自规则处理。动词原形的构成见[语法第 6 节](语法.md#6-动词)。

## 2. 元音拼写组合

| 组合 | 发音 |
|---|---|
| ai | [aɪ] |
| au | [aʊ] |
| ei | [eɪ] |
| oe | [ø] |
| eu | [ø] |
| ou | [əʊ] |

oi、ui也是允许的元音拼写序列；拼写许可与是否已有单独指定的整体音值分别记录。ui中的u按第1.2节处理。

上述表列组合按整体读取，oe、eu 中的 e 不受词尾 e 读 [ə] 的规则影响。oe、eu 对应单元音；ai、au、ei、ou 对应双元音。双元音可用于词族基本词干的元音构形与词尾变化；其他变化和派生基于单元音。纯辅音词根不含元音、不直接拼读，完整词干的构形见[构词](构词.md)。

## 3. 辅音拼写组合

| 组合 | 发音 |
|---|---|
| ch | [tʃʰ] |
| nn | 仅词尾 [ŋ]；一般位置 [n]，VnnV 分读两个 n |
| sh | [ʃ ~ ʂ] |
| ts | [tsʰ] |
| tz | [ts] |
| tc | [tɕʰ] |

nn 仅在词尾读 [ŋ]，例如 lonn [lɔŋ]；非词尾一般读 [n]，例如 nna [na]。VnnV 中两个 n 分读，例如 senna [senna]。分读时不在词中插入空格；空格只表示真正的词界。sh 允许读 [ʃ ~ ʂ]；[ʂ] 对应普通话 sh 的卷舌擦音。

## 4. 组合边界与音节

固定拼写组合一般不跨语素边界合读。复合词接合形成的 sh 连读为 [ʃ ~ ʂ]，例如 nas＋hes＋gron＋-ie → nashesgronie，接合处不分读 [s h]。跨成分 n＋n 仍保留各自的组成成分，不合读为 [ŋ]；包括词干末尾n与后缀开头n相接的情况。

三个元音连续的组合不出现，如 aia、aii。yy、ww、wy 不出现，yw 读 [jɯ]。

造词时避免复杂的复辅音音节，如 tch 这类组合。构成完整词干时，新增连缀从[辅音组合表](辅音组合.json)选择；该表用于新增连缀，既有词干的连缀保留。它不表示每种组合都可自由用于词首、词中、词尾全部位置。构词结构中分列的 t＋s 紧邻时可按 ts 合读，插入元音后可分开，构词位置不因此合并。元音组合限于第2节列出的组合、明确允许的oi／ui与双写长元音；i、u 在另一元音前的非音节用法，以及涉及 y、w 的组合另按第 1.2 节处理。tia、tua、tya、twa 均为合法拼写。动词后缀 -ie 按第 1.3 节的固定读音处理。除上述规则外，未列出的其他元音组合不使用。

## 5. 重音与音长

重音任意，不区别词义。同一个词可以改变重音位置，无须记忆固定的词汇重音。

音长通常不区别词义，个别词可以通过长短区别。词语采用固定的音长拼写，不能因通常不辨义而任意增删双写字母。双写元音表示长音，例如 aa [aː]、ii [iː]、uu [uː]。动词后缀 -ie 的长元音拼写按第 1.3 节处理。相同辅音音值连续出现时合读为一个，不读长辅音；[n] 例外，两个 [n] 保留分读。nn 的特殊拼读按第 3 节处理。







## 6. 西里尔参考拼写

西里尔参考拼写采用字母表中的对应关系，其中 c 对应 щ。固定组合 sh 整体对应 ш；复合接合处按第 4 节连读的 sh 也写 ш。明确分读的 s-h 写 с-х。nn 的西里尔参考拼写与读音规则一致：词尾读 [ŋ] 时写 ң，例如 lonn → лоң；一般位置读 [n] 时写 н，例如 nna → на；VnnV 分读时保留 нн，例如 senna → сенна。跨语素的 n-n 不合并。其余拼写组合按组成字母分别转写。保留大小写、双写、词素分界与真正的词间空格；不在词中插入空格。
